WanderPH

Philippine Destination Explorer — Site Plan

1. Site Name

WanderPH

WanderPH combines “Wander” with “PH,” the common abbreviation for the Philippines. The name is short, memorable, travel-focused, and immediately communicates that the website is about discovering destinations throughout the Philippines.

Brand idea: Discover the Philippines, one destination at a time.

2. Site Purpose

WanderPH is a Philippine travel discovery website that helps visitors explore destinations, compare places, find useful destination information, save favorite locations, and create a simple travel plan.

The site will provide destination cards with information such as location, description, category, attractions, and useful travel details. Visitors can search and filter destinations, open detailed destination information, save favorites using local storage, and submit a travel-planning form.

3. Scenarios

01

Finding a destination

“I want to find a beautiful Philippine destination for my next trip. Which places should I explore and what activities are available there?”

02

Planning a trip

“I already know where I want to go. How can I save the destination and submit my travel preferences so I can organize my trip?”

03

Choosing between destinations

“I have limited time. Can I filter destinations by category or search for a specific place before deciding where to travel?”

4. Color Scheme

WanderPH uses a fresh tropical palette inspired by the Philippine landscape, ocean, sunlight, and travel. The colors will be used consistently throughout the website.

Deep Teal#0B6E69

Primary brand color, headings, buttons, and navigation accents.

Sunset Orange#F4A261

Secondary accent, highlights, badges, and calls to action.

Ocean Navy#17324D

Primary text, footer, and strong-contrast elements.

Island Cream#F7F9F8

Page background and light content areas.

5. Color Scheme Use in Document

The selected WanderPH color scheme is used throughout this site plan. Deep Teal is used for the header and section headings. Sunset Orange is used for accents and calls to action. Ocean Navy is used for body text and dark wireframe elements. Island Cream is used for the page background and light surfaces.

Home Page Layout Notes

  • The header provides branding and simple navigation.
  • The hero introduces WanderPH and encourages exploration.
  • Search and filters help users quickly find destinations.
  • Destination cards present useful information in a scannable format.
  • The planning call to action leads users to the travel-planning form.
  • Mobile content is stacked; wider screens use a multi-column layout.

8. Valid HTML and CSS

This site plan uses semantic HTML5 elements including header, main, section, article, headings, lists, and buttons. The CSS is in a separate stylesheet and includes responsive media queries for mobile and wider screens.

The document includes a descriptive title, viewport meta tag, accessible heading structure, external CSS, and a responsive layout.

Validation checklist
  • Valid HTML5 structure
  • External CSS stylesheet
  • Responsive design
  • Proper document title
  • Semantic headings and sections
  • Consistent WanderPH color scheme
